Master Thesis – R Code

This repository contains the R scripts used for the data processing, analysis and visualisation conducted as part of my Master's thesis.

Contents

The repository contains the R code used for:

summarising species according to their IUCN Red List category;

comparing IUCN categories among vent molluscs, species examined in this study, and decapods;

calculating absolute and relative proportions of species within IUCN categories;

statistical test to answer the question: how expanding the taxonomic coverage affects the estimated proportion of threatened hydrothermal vent-endemic species and whether the proportion of threatened species differs significantly between the previously documented vent molluscs and the newly assessed species; 

visualising the global distribution and species richness of hydrothermal-vent endemic species using a 5° hexagonal grid.

The individual analyses and their corresponding steps are documented directly within the R scripts.

Data sources

The analyses are based on data from several sources:

This study: species and occurrence data collected and compiled as part of this study;

Vent molluscs: published IUCN data for hydrothermal-vent mollusc species;

Decapoda: a dataset compiled and processed within the research group.

The original data files are not included in this repository.

R packages

The analyses use R and several R packages for data processing, visualisation and spatial analysis. The required packages are specified directly in the corresponding R scripts.

Reproducibility

The scripts are provided to document the analytical workflow and the procedures used to generate the results presented in the Master's thesis.

Because the original datasets are not included in this repository, the analyses cannot necessarily be reproduced from the repository alone. Access to the underlying datasets and, where applicable, the relevant data sources is required.
